A page gets in only if two things are true. The material comes from about 2000–2010, and the page still loads on the live web today.

Proof comes from the page itself: due dates, semesters in the URL, period tools like Visual C++ 6.0, .dsp/.dsw files, CVS, Fedora Core, gcc 3.x, Bochs or Solaris machines.

GitHub recreations, Wayback-only pages, modern reposts and C++11+ material are left out. Open any card's “Why it's authentic” to see the evidence.
